## Comandos de reproducción

Ejecutar desde una copia local del repositorio, con XAMPP/MariaDB activos y una base de datos desechable. No usar datos de negocio.

### Servidor aislado usado para la prueba HTTP

La configuración temporal apuntaba a `prueba_hu02_http`; el esquema se preparó como copia de `database/schema.sql` sustituyendo el nombre de base. La copia de la aplicación estaba en `%TEMP%\hu02-http-app`.

En una terminal:

```powershell
php -S 127.0.0.1:8001 -t "$env:TEMP\hu02-http-app"
```

En otra terminal, desde la raíz del repositorio:

```powershell
$env:HU02_URL = "http://127.0.0.1:8001"
node .\docs\pruebas\evidencias\hu02-http.js
```

El script crea una materia de prueba que permanece en la base temporal. No lo ejecutes contra `sistema_inventario`.

### Integración PHP

La ejecución local reportada terminó con 42 comprobaciones correctas y utilizó un esquema anterior temporal para probar la migración. Para reproducirla, primero prepara el esquema anterior en una ruta temporal y configura localmente el DSN de pruebas según el script. Ejemplo de variables (sin credenciales incluidas):

```powershell
$env:HU02_PRUEBA_DSN = "mysql:host=127.0.0.1;port=3306;charset=utf8mb4"
$env:HU02_SCHEMA_ANTERIOR = "$env:TEMP\schema-anterior-hu02.sql"
# Si tu instalación lo requiere, define HU02_PRUEBA_USUARIO y
# HU02_PRUEBA_CLAVE solo en la sesión local; nunca los guardes en Git.
php .\pruebas\hu02-integracion.php
```

No se incluyen contraseñas ni credenciales. La ruta del esquema anterior debe apuntar a la copia temporal compatible que se usó para la prueba; no sobrescribas el esquema del proyecto ni ejecutes migraciones contra una base con datos reales.
